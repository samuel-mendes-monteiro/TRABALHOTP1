Descrição detalhada

Classe controladora da camada de apresentação para gerenciar interações de Board (Quadro).

Responsável por receber dados do usuário via terminal, validar as entradas, verificar permissões pelo papel da sessão e acionar os serviços através da interface IBoardService.

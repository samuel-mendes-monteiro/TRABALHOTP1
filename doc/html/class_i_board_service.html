Descrição detalhada

Interface abstrata que define os serviços relacionados à entidade Board (Quadro).

Contém o contrato de métodos virtuais puros para gerenciar quadros Kanban no sistema.

virtual bool IBoardService::updateBoard ( const Board & board)
pure virtual

Serviço 13: atualiza nome e limite de um quadro.

O identificador do quadro e o projeto ao qual ele pertence não são alterados.

Parâmetros
boardQuadro com os novos dados, identificado pelo seu identificador.
Retorna
true se foi atualizado, false se o quadro não existe.
Exceções
std::invalid_argumentse o novo limite for menor que o WIP atual do quadro.

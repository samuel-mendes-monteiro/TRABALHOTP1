Descrição detalhada

Interface abstrata que define os serviços relacionados à entidade Person (Pessoa).

Contém o contrato de métodos virtuais puros para gerenciar pessoas no sistema.

◆ updatePerson()

virtual bool IPersonService::updatePerson ( const Person & person)
pure virtual

Serviço 3: atualiza nome, senha e papel de uma pessoa.

O e-mail (chave primária) não é alterado.

Parâmetros
personPessoa com os novos dados, identificada pelo seu e-mail.
Retorna
true se foi atualizada, false se a pessoa não existe.
Exceções
std::invalid_argumentse o papel mudou e a pessoa ainda é gestora de projetos ou responsável por cartões.

Implementado por PersonService.

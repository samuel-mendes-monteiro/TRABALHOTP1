Descrição detalhada

Interface abstrata que define os serviços relacionados à entidade Project (Projeto).

Contém o contrato de métodos virtuais puros para gerenciar projetos no sistema.

virtual bool IProjectService::createProject ( const Project & project)
pure virtual

Serviço 6: cria um projeto.

Parâmetros
projectProjeto a ser criado; o e-mail do gestor deve estar preenchido.
Retorna
true se foi criado, false se já existe projeto com o mesmo identificador.
Exceções
std::invalid_argumentse o gestor não existe, se ele não tem o papel GESTOR ou se a data de término é anterior à de início.

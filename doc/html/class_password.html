Descrição detalhada

Classe que representa o domínio Password (Senha).

Uma senha consiste exatamente em 5 caracteres, podendo conter letras (a-z, A-Z) ou dígitos (0-9), devendo obrigatoriamente possuir pelo menos uma letra e um dígito.

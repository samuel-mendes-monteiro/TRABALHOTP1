Descrição detalhada

Classe controladora da camada de apresentação para gerenciar interações de Project.

Responsável por receber dados do usuário via interface de texto, validar as entradas, verificar permissões pelo papel da sessão e acionar os serviços correspondentes através da interface IProjectService.

◆ moveTask()

bool TaskService::moveTask ( const Identifier & identifier,
const State & newState,
const Timestamp & moveTime )
overridevirtual

Serviço 21: move um cartão entre colunas do quadro (A FAZER -> FAZENDO ou FAZENDO -> FEITO).

Parâmetros
identifierIdentificador do cartão a ser movido.
newStateNovo estado desejado.
moveTimeHorário em que a movimentação ocorreu; gravado como startDate (entrada em FAZENDO) ou endDate (entrada em FEITO), conforme a transição.
Retorna
true se a movimentação foi aplicada, false se a transição é inválida pelas regras do Kanban ou o cartão não existe.
Exceções
std::invalid_argumentse o limite WIP do quadro foi atingido ou se moveTime é anterior à data anterior do cartão (entrada ou início).
